# ПВЗ mahnet — Android-приложение сотрудника пункта выдачи

Приложение для сотрудников ПВЗ сайта **mahnet.ru**. Внутри — окно с сайтом `https://mahnet.ru/`
(те же логины и пароли сотрудников, что и в программе для Windows) и **родной сканер штрихкодов и QR-кодов**
(камера + Google ML Kit).

Что видит сотрудник:
- при первом запуске — окно «Вход для сотрудников» (логин и пароль из админки, вкладка «Сотрудники» / «Пункты выдачи»);
  дальше приложение само помнит вход;
- в шапке — **название пункта выдачи** и кнопка **«Уведомления»**;
- только те вкладки, которые админ отметил на сайте во вкладке **«Приложение ПВЗ»**
  (если для пункта ничего не отмечено — все вкладки, открытые сотруднику);
- во всех вкладках, где работает сканер (приём товара, выдача, возврат, отказы, склад),
  рядом со строкой ввода есть кнопка **«📷 Сканировать»** — открывается камера; найденный штрихкод или QR-код
  подставляется так же, как при работе ручного сканера;
- **потяните экран вниз** — данные обновятся с сервера; вообще сайт сам обращается к серверу каждые 1,5 секунды
  и подтягивает чужие изменения, а при возврате в приложение обновляется сразу;
- нажатие на название пункта в шапке открывает окно «О складе / пункте» с кнопкой **«Выйти»**;
- кнопка «Назад» сначала закрывает окна сайта, а если закрывать нечего — сворачивает приложение.

## Как собрать APK на GitHub (без Android Studio)

1. Зайдите на https://github.com и создайте новый репозиторий (лучше приватный), например `market-pvz`.
2. Распакуйте этот архив и загрузите **все файлы проекта** в репозиторий
   (кнопка *Add file → Upload files*; папку `.github` тоже — это важно, в ней сборка).
   Если GitHub не показывает папку `.github` при выборе файлов, перетащите папку целиком мышкой.
3. Откройте вкладку **Actions**. Сборка *Build Android APK* запустится сама после загрузки файлов.
   Если нет — выберите её слева и нажмите **Run workflow**.
4. Через 3–6 минут сборка станет зелёной. Откройте её и внизу, в разделе **Artifacts**,
   скачайте `pvz-apk` (zip с файлом `app-debug.apk`).
5. Скопируйте `app-debug.apk` на телефон и откройте. Android попросит разрешить установку
   из этого источника — разрешите. При первом нажатии «Сканировать» разрешите доступ к камере.

Если сборка покажет красный крестик — откройте её, скопируйте текст ошибки из шага *Build debug APK*
и пришлите мне, я поправлю.

## Обновление приложения по воздуху
1. Соберите новую версию на GitHub (любой новый запуск Actions увеличивает номер версии: 1.0.1, 1.0.2…).
2. На сайте: админка → **«APK файлы»** → строка **«Приложение ПВЗ»** → впишите номер версии (например `1.0.2`),
   загрузите `app-debug.apk`.
3. Сотрудники при следующем запуске увидят окно «Доступно обновление», приложение скачает файл и откроет установку.
   Первую установку можно сделать по ссылке, которая показана во вкладке «Приложение ПВЗ».

> Для обновления по воздуху нужен обновлённый `api.php` (в нём добавлена строка `pvz` в список приложений) —
> он лежит в новом `mahnet_upload.zip`.

## Версии и подпись
- Версия приложения: **1.0.N**, где N — номер сборки на GitHub. Первая сборка — 1.0.1, следующая — 1.0.2.
- Все сборки подписаны одним и тем же ключом (`app/market-release.p12`), поэтому новый APK **устанавливается поверх
  старого** как обновление, вход сохраняется.
- **Не удаляйте и не меняйте файл `app/market-release.p12`.** Репозиторий лучше держать приватным.
- Идентификатор приложения — `ru.mahnet.pvz`. Название на телефоне — «ПВЗ mahnet», значок — ваша картинка.

## Что внутри
- `app/src/main/java/ru/mahnet/pvz/MainActivity.kt` — окно сайта, сканер, «потянуть вниз», кнопка «Назад».
  Адрес сайта — `BASE_URL` в начале файла.
- `app/src/main/java/ru/mahnet/pvz/Updater.kt` — обновление по воздуху (строка `APP = "pvz"`).
- `app/src/main/res/mipmap-*` — значок приложения (из присланного изображения; `icon-512.png` — крупная копия).
- `.github/workflows/build.yml` — автоматическая сборка на GitHub.

## Как это работает со сканером
Сайт определяет, что открыт в приложении (в имени браузера есть `MahnetPVZApp`, есть объект `window.PvzApp`),
и по кнопке «Сканировать» просит приложение включить камеру. Приложение находит штрихкод (Code 128, EAN, Code 39)
или QR-код и передаёт его сайту; сайт подставляет его в строку ввода открытой вкладки и нажимает Enter — ровно так,
как это делает ручной сканер. В приёмных вкладках (приём на ПВЗ, склад, отказы) камера остаётся открытой
и показывает результат после каждого товара, в «Выдаче товара» и «Возврате» — закрывается после первого кода,
чтобы вы увидели карточку покупателя.

## Публикация в Google Play (по желанию)
Собирается отладочный APK (`app-debug.apk`) — он ставится на телефоны напрямую. Для Google Play нужна подписанная
сборка (release) со своим ключом — скажите, подготовлю.

## Сброс версии на 1.0.0
Версия приложения — `1.0.N`: первая сборка после сброса получает **1.0.0**, дальше 1.0.1, 1.0.2…
В файле `app/version-base.txt` записано слово `auto`: при первой же сборке на GitHub оно само заменится
нужным числом (шаг «Версия (счёт с 1.0.0)» в *Actions*; затем сборка сама сохранит его в репозитории).
Ничего вписывать вручную не нужно. Если шаг «Запомнить счётчик версии» покажет красный значок (в репозитории запрещена запись
из Actions) — откройте *Settings → Actions → General → Workflow permissions* и включите *Read and write permissions*
либо впишите в `app/version-base.txt` число (номер последней сборки до сброса).
Чтобы снова сбросить счёт на 1.0.0 — запишите в `app/version-base.txt` слово `auto` и запустите сборку.
Внутренний номер Android (`versionCode`) при этом не уменьшается, поэтому новая сборка ставится поверх старой.
Если вы создали **новый репозиторий** (номера сборок начинаются с 1), старое приложение на телефоне нужно сначала удалить.
Не забудьте во вкладке админки «APK файлы» загрузить новый APK и указать версию `1.0.0` (или удалить старую запись),
иначе приложение будет предлагать «обновиться» до старой версии.
